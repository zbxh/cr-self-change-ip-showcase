# 自助更换 IP 使用指南

适用于 **2.2.4**。正式包可通过开发者获取。

## 1. 安装与检查

1. 准备已安装魔方云模块的 V10 站点，先备份网站和数据库。
2. 通过 V10 应用管理安装或升级。服务器端部署时，将包内的 `self_change_ip` 放入 `public/plugins/addon/`，在应用列表搜索「自助更换IP」并安装。
3. 打开插件设置，核对版本、系统任务和魔方云模块。使用邮件或短信时，先配置 V10 通知模板和发送接口。

## 2. 配置并发布规则

1. 在「商品规则」选择商品，配置免费与付费条件、价格和申请要求。
2. 如需保留 IP 库存，在「IP 资源规则」设置适用商品和更换后保留的数量。
3. 在「用户规则」配置全局默认或特定用户、等级的免费和付费次数，核对周期后发布商品规则。

[商品规则](images/product-rules.png) · [IP 资源规则](images/resource-groups.png) · [客户额度](images/user-quota.png)

## 3. 客户发起更换

1. 在会员中心打开自助更换入口，选择本人名下符合条件的云服务器。
2. 查看额度与报价，填写可选申请原因并确认。需审核时等待后台处理，需付款时通过原生订单支付。
3. 在更换记录查看执行结果。结果待核对时，继续查看原申请进度。

[更换报价](images/member-quote.png) · [更换记录](images/member-history.png)
